## 一、开播前检查

### 1.1 直播安排（提前一个月起）

- [ ] **提前一个月**确认直播主题，并在视频号后台设置开播预告（生成预告二维码）。时间充裕时尽量一次确定三场以上直播，以防后续来不及确认（据宋营交接文档）。
- [ ] **提前两周至一周**制作并确定直播海报/预告视频，海报确认后立即安排转发时间与文案，交由教务转发（据宋营交接文档）：
  - 家长大群：群公告 + 宣传海报/视频；
  - VIP 群：内容文案 + 宣传海报/视频。
- [ ] 海报、预告视频、直播文案均须与祁老师确认（据宋营交接文档）。
- [ ] ⚠ 不一致：宋营文档“直播相关”部分写海报提前两周至一周确定，“美工制图”部分写“直播前 2 天确认好直播文案”，两者节奏不同，以郑峰确认为准。
- [ ] 已准备好直播中需发送并置顶的评论文案（见第四章）。

### 1.2 直播素材（提前两周至一周制作）（据宋营交接文档）

| 素材 | 要求 |
| --- | --- |
| 外围背景图 | 内容重点突出；文字和 LOGO 不宜太靠边，直播时边缘会被“吃掉”，尽量紧凑居中 |
| 贴片 | 颜色醒目；放到背景上时整体放大，避免字小看不清；不得遮挡人脸，画面协调 |
| 开播前封面 | 尺寸 **3:4** |

### 1.3 设备调试（开播前 6 小时）（据宋营交接文档）

- [ ] 调试设备，确认三脚架位置；将直播海报和背景图拷贝到推流电脑。
- [ ] 打印 A4 直播大纲贴在墙上，或使用平板提词器：**横版、字号放到最大、一个大要点一页**。
- [ ] 确认画面摆正、大小合适，不出现整体缩小或放大。
- ⚠ 不一致：宋营文档“直播相关”写开播前 6 小时调试，“美工制图”写“直播当天须提前 1–2 小时测试流程”，“直播流程”注意事项写“第一次直播前需要提前测试流程”。建议以 6 小时为准，待郑峰确认。

### 1.4 开机与连线顺序（据宋营交接文档“直播流程”）

1. 打开排插开关，依次打开灯、电脑、相机、导播台等设备。
2. 相机**须使用外接电源**，装好后安装在三脚架上，摆正三脚架和相机位置。
3. 打开**发射器和接收器**电源，二者连接后，导播台即显示相机画面。
4. 电脑上打开 **OBS 和 YY 直播**，此时两者都应能显示相机画面。（YY 在当前流程中的作用【待确认】，见文末问题）
5. 在 OBS 中替换为本场制作好的直播背景。
6. 如需展示直播大纲：打开白色桌上的电脑，用高清线连接电视，将电脑投屏到电视，把大纲导入 PPT 播放。

| 发射器 / 接收器 | 相机信号经其传到导播台（据宋营交接文档） | 型号、配对方式 |

### 1.5 开播前约 1 小时（据宋营交接文档）

- [ ] 请**郑老师扫码登录**视频号助手（视频号「祁绩教育培训」由郑老师微信扫码登录，据宋营交接文档）。
- [ ] 将直播画面尺寸调整为 **9:16**，放好直播背景和贴片。
- [ ] 检查“无他相机”是否已登录、是否开通会员、画面有无水印；检查画面源、播放器声音等细节。（“无他相机”在相机 + 导播台方案中的具体作用【待确认】）

### 1.6 开播前 10 分钟

- [ ] OBS 画面确认无误，背景/贴片上的联系方式正确。
- [ ] ATEM 硬盘录制已就绪（见第三章）。
- [ ] 全员手机静音，现场人员到位。

## 二、OBS 场景

### 2.1 画面构成

- 画面比例：**9:16 竖屏**（据宋营交接文档）。
- 结构：中间为导播台输出的相机画面，四周为**外围背景图**，其上叠加**贴片**（与已知的“上下留白放联系方式等信息”一致）。
- 背景与贴片的制作要求见 1.2（据宋营交接文档）。
- 联系方式具体内容（电话、二维码对应账号）【待确认】。

### 2.3 推流步骤（据宋营交接文档）

1. 打开视频号助手 →「直播」→ 选择 **推流直播**。
2. 选择直播封面（3:4）并填写主题 →「创建直播」。
3. 将**推流地址**和**推流密钥**复制到 OBS「设置 → 直播」（服务选“自定义”）。推流密钥不得外传。
4. OBS 开始推流，确认视频号助手已收到画面后，在视频号上点击 **开始直播**。
5. 推流分辨率、码率、编码器以现有配置为准【待确认】，调整须先报备郑峰。

### 2.4 注意事项

- 直播中不随意改动场景；修改场景后建议导出场景集合备份，存放位置【待确认】。

## 四、评论操作

### 4.1 现行做法（据宋营交接文档）

直播期间由运营人员负责直播间互动：

1. **监听声音**：用自己的手机进入直播间，确认有无声音、音量是否合适、有无杂音，发现问题立即调整。
2. **拉人气**：在**钉钉大群**通知没课的行政老师、教务老师进直播间观看并点赞。
3. **转发**：开播后把直播间转发给教务（方燕铭），由其转发到对应年级的微信大群提醒家长；或由祁老师用手机转发朋友圈。
4. **评论互动**：
   - 手动回复评论区家长关心的问题；
   - 挑选家长关心的问题反馈给直播老师在线解答；
   - 把老师讲的重点总结后发到评论区并**置顶**；
   - 随时在评论区提醒家长可以提问；
   - 记录问题，下播后整理反馈给祁老师。
5. **记录时间点**：记录讲解要点与置顶内容对应的时间，方便后期回放切片剪辑。
6. **控时**：快超过约定时间时，及时提醒直播老师收尾。

### 4.2 改进建议【建议·待郑峰确认】

- 由一名同事在**视频号助手网页版**专职发送、置顶评论，替代手机手打；预先把固定文案（报名方式、联系方式等）整理成文本逐条复制。
- 网页版是否支持置顶【待确认】，如不支持，改用手机端置顶。
- 涉及价格、优惠、承诺性表述的评论须事先经郑峰确认。

## 五、下播后归档与剪辑

### 5.1 回放处理（据宋营交接文档）

1. 能生成回放时**第一时间生成直播回放**，并设置为**仅自己可见**。对外一律说明没有直播回放，以直播为准。
   - ⚠ 不一致：宋营文档另外两处写“结束直播后第二天记得保存回放”。建议以“当天第一时间生成并设为仅自己可见”为准，待郑峰确认。
2. 回放下载后上传到对应的 NAS 文件夹，并发送给**祁老师、罗老师和负责的运营老师**。
3. 把回放视频放到 **有赞/小鹅通** 后台的“视频号直播回放”专栏存档，生成有效链接供老师内部学习，**禁止外传**。（目前使用有赞还是小鹅通【待确认】）
4. 祁老师要求剪辑回放用于视频号宣传时，按既定要求剪辑；不需要剪辑时，只需确保存储到位。

### 5.2 直播复盘文档（据宋营交接文档）

- 按模板整理“直播安排分析”文档：直播后台数据分析（附直播结束后的数据截图）、遇到的问题和情况。
- 发给祁老师和郑老师审阅，确认无误后一起存入 NAS 直播回放文件夹。
- 往年直播安排文档位置：`2运营硬盘文件备份-2026年祁绩-直播及线下安排文档`、`2运营硬盘文件备份-2025年祁绩-直播及线下沙龙安排文档`（据宋营交接文档）。模板文件具体位置【待确认】。

### 5.3 收尾与硬盘录制归档

1. 视频号助手结束直播 → OBS 停止推流（及录制）→ 停止 ATEM 录制并确认文件完整 → 安全弹出硬盘 → 设备关机断电。
2. 将 ATEM 工程文件夹完整复制到 NAS **qijisch**：`/volume1/运营资料/1直播相关硬盘/` 对应年份目录。宋营文档中的对应路径为“NAS-运营资料-直播相关硬盘-25年直播硬盘录制文件”（据宋营交接文档），与此一致。
3. 复制后核对文件数量和大小，清理录制硬盘须经郑峰同意。
